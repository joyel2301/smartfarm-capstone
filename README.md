# 2025년 2학기 스마트팜 창의설계 3조 
## 개요
이 프로젝트는 전북대 스마트팜 창의 설계의 일환으로 2025년 9월1일 부터 12월 21일까지 수행함

## 팀
팀명: RGB

팀원 및 역할
- 김기강: 아이디어 구체화, 개발 총괄
- 송수정: 대시보드 디자인, 데이터 시각화
- 김대웅: 데이터 시각화
## 주제 및 기대효과
- 프로젝트명: 온실 데이터 통합 대시보드 개발
  1. 온실에서 나오는 환경 데이터, 생육데이터 와 날씨 api를 받아 차트로 시각한 대시보드 개발
  2. GPT api와 RAG를 활용한 농업 비서 개발
  3. 병해충 관리 시스템 개발

 -  기대 효과
  1. 저비용으로 접근 가능한 스마트팜 관리 소프트웨어 제공
  2. 한눈에 보이는 UI로 쉽게 학습및 활용 가능
  3. 감에 의존하던 기존방식을 탈피하여 데이터로 농사 가능
  4.  RAG 기반 AI 상담기능으로 정보 탐색 비용 감소 기대
## 기능
- 온실의 현황을 알수있는 대시보드
  - 온실 환경데이터
  - 생육데이터
  - 날씨 데이터
  - 온실 관리 제어 현황
- 병해충 관리 시스템
  - 언제 어디에 어떤 약을 얼마나 주었는지 확인 가능
- RAG를 이용한 농사 비서
